# oach.me

> Цифровой сад · Хаб проектов · Портфолио по электронной инженерии

Личный сайт [OACH](https://oach.me) — Электронная инженерия · FOSS · Цифровой суверенитет.
Построен на [Astro](https://astro.build) и TypeScript. Без трекеров, без телеметрии,
без внешних зависимостей во время выполнения.

---

## Зачем существует этот сайт?

Этот сайт — **Цифровой сад**: живое пространство, где документируется пересечение
низкоуровневого кода и осязаемого железа — как инструкции взаимодействуют с кремнием,
производя измеримые эффекты в физическом мире.

Это не маркетинговое портфолио. Это практическое воплощение двух принципов, которые
управляют всем стеком:

- **Техническая прозрачность** — если я выступаю за проверяемые процессы, минимум —
  сделать собственный код открытым для инспекции. Поэтому репозиторий публичен.
- **Цифровой суверенитет** — сайт не собирает данные, не использует сторонние аналитики,
  не включает внешние скрипты во время выполнения. Пользователь — не продукт.

## Визуальная идентичность

Палитра **Catppuccin Mocha** выбрана потому, что она вызывает ассоциации с современным
эффективным терминалом — глубокий тёмный фон (`#11111b`), акценты в mauve, sapphire, teal
и peach, обеспечивающие визуальную иерархию без отказа от технической эстетики.

```
Фон:      --crust    #11111b  /  --mantle  #181825  /  --base  #1e1e2e
Текст:    --text     #cdd6f4  /  --subtext #bac2de
Акценты:  --mauve    #cba6f7  /  --sapphire #74c7ec  /  --teal #94e2d5
```

Шрифт **Azeret Mono** (моноширинный с широкими пропорциями) усиливает техническую
идентичность: весь сайт — от заголовков до основного текста — использует одну семью.
Никакой декоративной или sans-serif типографики, нарушающей целостность.

**Система glass** (`.glass`, `.glass-featured`) применяет `backdrop-filter: blur` и
анимированную рамку через `@property --border-angle` — непрерывно вращающийся градиент
рамки, рассчитанный так, чтобы не отвлекать в покое, но быть заметным при наведении.

## Динамические теги — GitHub API

Теги языков программирования на карточках проектов **генерируются во время сборки**,
а не хардкодятся:

```typescript
// src/lib/github.ts
export async function fetchLangTags(repo: string): Promise<string[]> {
  const res = await fetch(`https://api.github.com/repos/${repo}/languages`);
  const langs: Record<string, number> = await res.json();
  return Object.keys(langs)
    .filter(l => !NOISE.has(l))        // фильтрует HTML, CSS, Shell...
    .map(l => EMOJI[l] ? `${EMOJI[l]} ${l}` : l);
}
```

Во время `astro build` сайт обращается к GitHub API для каждого проекта с заданным
`githubRepo` и объединяет результат со `STATIC_TAGS` (`🔓 Open Source`, `⚡ KISS`). Если
API недоступен, сборка продолжается без динамических тегов — деплой не блокируется.

## Запуск локально

```bash
git clone https://github.com/OACH-py/oach.me
cd oach.me
npm install
npm run dev      # http://localhost:4321
npm run build    # статическая сборка → dist/
npm run preview  # предпросмотр сборки
```

Переменные окружения не требуются. GitHub API публичен для неаутентифицированных запросов
(лимит 60 запр./ч на IP — достаточно для любой локальной сборки).
